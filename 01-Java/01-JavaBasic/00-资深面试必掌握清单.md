# Java 核心 · 资深 / 专家面试必掌握清单

> **适用岗位**：Java 资深 / 专家
> **覆盖范围**：road-java（语言核心 / 集合 / 并发 / JVM / 新特性）
> **核心原则**：不追求"全都会背"，只追求"**该会的能扛住追问**"

---

## 0. 使用说明

### 0.1 掌握程度分级

| 代号 | 含义 | 检验方式（做不到就不算） |
|---|---|---|
| 🗣 **能说** | 用自己的话讲清结论 + 核心原理 | 出声讲 1 分钟不卡壳 |
| ✍️ **能写** | 能手写关键代码 / 伪代码 | 白板手写，不看答案 |
| 🖊 **能画** | 能画出机制图 | 白纸画出 JMM / AQS / GC 分代 |
| 🔁 **能扛** | 扛 3 层追问（原理 → 源码/边界 → 坑与权衡） | 连续追问不露底 |
| 🔗 **能连** | 能联系项目场景举例 | "我在邮储交易里遇到过……" |

### 0.2 优先级

- **P0 必精通**：高频必问 → 必须达到 🔁 能扛 **且** 🔗 能连
- **P1 应掌握**：常见 → 达到 🗣 能说 +（✍️ 能写 或 🖊 能画）
- **P2 了解**：能说结论即可，答不出不致命

### 0.3 自测规则

1. 每点**合上资料**，先出声讲一遍；
2. 讲得出 → 立刻**降维追问自己 2\~3 层**（为什么？源码？边界？坑？）；
3. 卡住 → 回锚点补，**3 天后重讲**；
4. **P0 点只到 🗣「能说」= 未达标。**
