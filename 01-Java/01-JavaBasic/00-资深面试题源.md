# 一、语言核心（01-JavaBasic）

## 大问题 ① ｜封装 / 继承 / 多态

### A. 封装

**点 A1 访问控制**

- ★「`protected` 的方法，不同包的子类能调用吗？那 `new Parent().m()` 呢？为什么编译会报错？」
- ☆「四种访问修饰符的可见范围分别是？」

**点 A2 可变性防御**

- ☆「你的对象里有个 `Date` 字段，外部能改到你内部的状态吗？怎么防？」
- ☆「不可变对象要同时满足哪几个条件？」
- –「`record` 和普通类有什么区别？什么时候用？」

**点 A3 封装的性能误区**

- ☆「封装都用 getter，每次调用都有一次方法调用，有性能开销吗？」

### B. 继承

**点 B1 基础 + 初始化**

- ★「`new` 一个子类对象，构造器的执行顺序是怎样的？」
- ★「父类没有无参构造器，子类为什么编译报错？怎么解决？」
- ☆「静态块、实例块、构造器的执行顺序？」
- ☆「一个类什么时候才会被初始化？」

**点 B2 重写规则**

- ★「重写有哪些规则？返回类型、抛出异常、访问权限分别有什么限制？」
- ☆「`@Override` 不写行不行？它有什么用？」

**点 B3 构造器陷阱**

- ★「父类构造器里调用了一个被子类重写的方法，会发生什么？」
- ☆「为什么说构造器里不该调用可重写的方法？」

**点 B4 继承 vs 组合**

- ★「什么时候用继承，什么时候用组合？」
- ☆「继承有什么缺点？举个例子。」
- ☆「`Stack extends Vector` 为什么被说是设计失误？」

### C. 多态

**点 C1 表现**

- ★「重载和重写的区别？它们分别在什么时候确定？」
- ☆「向上转型和向下转型？什么时候会抛 `ClassCastException`？」

**点 C2 底层机制（🖊 能画）**

- ★「`Animal a = new Dog(); a.sound();` 运行时怎么找到要执行的那个方法？」
- ★「什么是虚方法表？它存在哪？每个类一张吗？」
- ☆「动态分派的过程是怎样的？」

**点 C3 绑定时机**

- ★「父类引用指向子类对象，`o.x` 和 `o.getX()` 分别输出什么？为什么？」
- ★「静态方法能被重写吗？`private` 方法呢？」
- ☆「为什么说字段是静态绑定、方法是动态绑定？」

**点 C4 易错 + 应用**

- ★「`null` 传给重载方法，会调哪个重载？为什么？」
- ☆「重载时传基本类型 / 包装类型，怎么选？」
- ★「你项目里哪里用到了多态？策略模式怎么体现多态的？」
